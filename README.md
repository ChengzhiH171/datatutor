# DataTutor —— 大数据技术学科垂类智能教学助手

面向一流学科建设的学科垂类大模型与创新应用开发平台，基座模型为**讯飞星火认知大模型 V4.0**。

## 架构



## 已实现功能

| 功能 | 说明 |
|------|------|
| AI 实训副驾 | 讯飞星火对接终端 WebSocket，实时辅导学生操作 |
| AI 课程生成 | Teacher Agent 自动生成实训课程名称、描述和子任务清单 |
| 组件配置向导 | 引导式大数据组件环境搭建（Hadoop/Spark/Hive 等） |
| Docker 隔离实训 | 每个学生独立容器，含完整大数据工具链 |
| 多角色管理 | 学生/教师/管理员三端分离，课程班级管理 |
| 学情分析 | 学生进度追踪、任务完成率统计 |
| 知识库问答 | 大数据领域知识 RAG 问答 |
| 实训报告生成 | Report Agent 自动生成学生实训报告 |

## 技术栈

- **后端**: Python 3.8 / Flask / Flask-SocketIO / SQLAlchemy
- **数据库**: MySQL 8.0 / Redis 7
- **AI 引擎**: 讯飞星火认知大模型 V4.0 (星辰 MaaS Agent API)
- **容器化**: Docker / Docker Compose
- **前端**: HTML5 / Tailwind CSS / Iconify

## 讯飞星火 Agent

本项目对接讯飞星辰工作流平台 4 个 Agent：

| Agent | Flow | 用途 |
|-------|------|------|
| 实训副驾 | XUNFEI_FLOW_TRAINING | 终端内实时对话辅导 |
| 知识问答 | XUNFEI_FLOW_KNOWLEDGE | 大数据领域知识检索 |
| 课程生成 | XUNFEI_FLOW_TEACHER | AI 自动生成实训课程 |
| 报告生成 | XUNFEI_FLOW_REPORT | 学生实训报告自动生成 |
