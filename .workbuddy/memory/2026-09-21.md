## 终端黑屏问题定位与修复

**用户问题**：实训终端面板打开后只剩光标和一片黑（main.html 截图）。

**根因链**：
1. 后端没启动（80 端口空），socket.io 不通 → `terminal_connect` 事件没人响应
2. 学生角色自动连接失败时无任何提示（连接表单被隐藏）
3. `datatutor-student` Docker 镜像未构建（即便后端起来，自动 `docker run` 也会失败）
4. `flask_socketio`、`eventlet` 等依赖未安装

**修复动作**：
- 创建隔离 venv `C:/Users/曹植/.workbuddy/binaries/python/envs/datatutor`，pip 安装 backend/requirements.txt
- `docker build -f Dockerfile_student -t datatutor-student E:\data\datatutor`（22 分钟，Ubuntu 镜像大）
- 后台启动 `python app.py`（80 端口监听，PID 24704）
- 编写 `backend/verify_terminal.py` 端到端验证脚本：用 student1/123456 登录，模拟浏览器 socketio 客户端，触发自动创建容器 + SSH 连通 + 命令往返

**验证结果**：✅ 端到端通过，dts-student2 容器已起来（127.0.0.1:2202→22），Ubuntu welcome banner 回显，echo 命令交互正常。

**学到的运维要点**（以后再做这类启动可复用）：
